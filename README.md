# Ankan Gaming Zone 🎮

Welcome to **Ankan Gaming Zone** – the ultimate gaming arena with awesome interactive mini-games built with web technologies! 

This project aims to provide a seamless, modern, and engaging gaming experience in the browser.

## 🚀 Features

- **Mini-Games Collection:** Play classic favorites like *Tic-Tac-Toe* and *Snake*.
- **Modern UI/UX:** Built with Bootstrap 5 and custom CSS for a premium, sleek neon and glassmorphic aesthetic.
- **Responsive Design:** Enjoy gaming across desktop, tablet, and mobile devices natively.
- **Smooth Animations:** Includes subtle micro-animations for an elevated user experience.

## 🛠️ Technology Stack

- **HTML5:** Semantic structure and built-in SEO optimizations.
- **CSS3:** Custom styles and animations.
- **JavaScript (jQuery):** Game logic and interactivity.
- **Bootstrap 5:** Responsive grid and pre-built scalable layouts.
- **FontAwesome:** Scalable vector icons.
- **Google Fonts:** Custom typography (Orbitron, Roboto).

## 📂 Project Structure

```
Ankan-Gaming-Zone/
├── CSS/                  # Stylesheets and theming
├── JS/                   # Core scripts and logic
├── Games/                # Individual mini-game source folders (Snake, Tic Tac Toe)
├── include/              # Shared template files (e.g., footer.html)
├── index.html            # Main Landing Page
├── about.html            # About the Platform
├── games.html            # Game Selection Hub
├── contact.html          # Contact Information
└── README.md             # Project Documentation
```

## 🎮 How to Play

1. **Clone or Download:** Extract the project files to your local machine.
2. **Launch:** Open `index.html` in any web browser.
3. **Explore:** Navigate through the intuitive UI to find and play your favorite online games.
